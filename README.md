# Finance Tracker

A modern Finance Tracker web application built using React, Firebase, and Tailwind CSS. The application allows users to manage their income and expenses securely with Firebase Authentication and visualize their financial data through an interactive dashboard.

## Features

### Authentication

* User Registration using Email and Password
* User Login
* Secure Authentication using Firebase Authentication
* Logout Functionality

### Dashboard

* Modern Responsive UI
* User Profile Display
* Dark / Light Theme Toggle
* Financial Summary Cards

  * Total Income
  * Total Expenses
  * Current Balance

### Transaction Management

* Add Income Transactions
* Add Expense Transactions
* Real-time Data Storage using Firebase Firestore
* View Transaction History
* Delete Transactions

### Analytics

* Expense Distribution Pie Chart
* Automatic Expense Calculation
* Real-time Dashboard Updates

### User Data Security

* User-specific transactions using Firebase UID
* Data isolation between users
* Secure Firebase Firestore integration

## Tech Stack

### Frontend

* React.js
* React Router DOM
* Tailwind CSS
* React Icons
* Recharts

### Backend / Database

* Firebase Authentication
* Firebase Firestore Database

## Installation

1. Clone the repository

git clone https://github.com/ashish-s23/finance-tracker.git

2. Navigate to project

cd finance-tracker

3. Install dependencies

npm install

4. Start development server

npm run dev

## Firebase Setup

1. Create Firebase Project
2. Enable Authentication
3. Enable Email/Password Login
4. Create Firestore Database
5. Add Firebase configuration in firebase.js
